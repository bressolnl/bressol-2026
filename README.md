# Bressol 2026

Proyecto e-commerce WordPress + WooCommerce desarrollado desde cero.

## Objetivos
- SEO técnico y de contenidos
- Experiencia de compra premium
- Sistema de packs y upsells
- Funnels y tracking orientado a Ads
- Escalabilidad futura (España / nuevos packs)

## Reglas del proyecto
- El tema contiene solo UI/UX y plantillas
- La lógica de negocio vive en plugins propios
- WordPress no inyecta scripts de tracking
- Todo el tracking pasa por Google Tag Manager
