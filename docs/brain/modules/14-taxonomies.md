# Modulo Taxonomies

Proposito
- Registrar la taxonomia `bressol_moment` para productos.
- Exponerla en admin y REST.

Detalles
- Taxonomia: `bressol_moment`
- Tipo: no jerarquica (tipo tag).
- Visible en admin y REST.
- Columna en listado de productos con CSS ajustado.
