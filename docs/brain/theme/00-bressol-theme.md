# Bressol Theme

Proposito
- Capa UI/UX, plantillas y SEO on-page.
- Mantener el theme libre de logica de negocio.

Estado actual
- `functions.php` solo registra soportes basicos (title-tag, thumbnails, woocommerce).
- `header.php`, `footer.php`, `index.php` son esqueletos minimos.
- CSS/JS aun no cargados.

Reglas
- No incluir logica de packs, wizard, recomendaciones ni tracking.
- El plugin empuja dataLayer; el theme solo pinta markup.
