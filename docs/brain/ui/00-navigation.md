# Menú principal (header)

## Configuración

- Ve a **Apariencia → Menús**.
- Crea o edita un menú y asígnalo a la ubicación **Hoofdnavigatie**.
- Añade los enlaces principales (p. ej. Pakketten, Advies, Momenten).

## Comportamiento

- Si no hay menú asignado, el tema muestra los links fallback por defecto.
- Las acciones de la derecha (buscar, cuenta, carrito) se mantienen como botones con paneles existentes.
