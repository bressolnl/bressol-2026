Día 2 — WordPress local y conexión con el repo

Qué se ha hecho:
- Analizada la estructura de WordPress (core vs proyecto)
- Localizada la carpeta del site en LocalWP
- Instalado WooCommerce de forma limpia
- Verificado funcionamiento básico de tienda
- Preparada estructura wp-content dentro del repo
- Conectado WordPress local al repo mediante symlinks
- wp-content/themes y wp-content/plugins controlados por Git
- WordPress reconoce bressol-theme y bressol-core desde el repo

Qué he aprendido:
- WordPress core no forma parte del proyecto
- El proyecto vive únicamente en theme y plugins propios
- Usar symlinks permite separar entorno y código
- Git debe controlar solo el código, no los datos
