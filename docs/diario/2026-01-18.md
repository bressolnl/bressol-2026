Día 8 — Base técnica de Packs configurables (MVP)

Qué se ha hecho:
- Diseñada la arquitectura base de Packs dentro de bressol-core
- Implementado módulo Packs con separación Admin / Frontend / WooCommerce
- Definido modelo de packs mediante JSON en post meta del producto
- Creada metabox para definir slots y opciones del pack
- Implementado guardado robusto del JSON mediante AJAX (compatible con editor moderno)
- Implementada UI frontend para selección de opciones del pack
- Implementada validación obligatoria antes de añadir al carrito
- Implementado sistema de recargos por opción seleccionada
- Ajustado el precio final del pack en el carrito (precio base + suplementos)
- Mostrada la selección del pack como meta en carrito y checkout
- Validado el flujo completo con un pack real de aceites (IDs 68–73)

Qué he aprendido:
- Los metabox clásicos no son fiables con el editor de productos moderno
- Usar AJAX para guardar configuraciones complejas es más robusto
- Un pack debe tratarse como un producto contenedor con lógica propia
- Separar lógica Admin / Frontend / Woo facilita escalar funcionalidades
- Los recargos deben aplicarse sobre el precio del producto en el carrito, no antes
